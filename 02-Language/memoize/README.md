# memoize

Иногда результат дорогой функции нужно вычислить лениво и затем использовать много раз.

Реализуйте `Memoize`. Функция получает `Func` и возвращает новую функцию с той же сигнатурой.

Обёртка должна:

- не вызывать исходную функцию до первого обращения к обёртке;
- вызвать исходную функцию ровно один раз;
- запомнить и значение, и ошибку первого вызова;
- возвращать эту же пару при всех следующих вызовах.

Ошибка тоже является результатом вычисления. Если первый вызов вернул ошибку, повторять исходную операцию не нужно.

Каждый вызов `Memoize` создаёт независимый cache, даже если исходная функция у обёрток одна и та же.

`Memoize(nil)` должен завершиться паникой. Потокобезопасность не требуется: обёртку будут вызывать только последовательно.
