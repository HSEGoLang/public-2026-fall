# bankaccount

Реализуйте небольшой пакет для работы с банковскими счетами.

Сумма задаётся типом `Money`. Баланс счёта скрыт внутри пакета: изменять его можно только через функции из `account.go`.

Zero value типа `Account` — корректный пустой счёт с нулевым балансом.

Нужно реализовать:

- `NewAccount` — создать счёт с неотрицательным начальным балансом;
- `Balance` — получить текущий баланс;
- `Deposit` — пополнить счёт;
- `Withdraw` — снять деньги, если их достаточно;
- `Transfer` — атомарно перевести деньги между двумя счетами.

Здесь _атомарно_ означает только «всё или ничего»: если перевод невозможен, ни один баланс не меняется. Потокобезопасность и `sync/atomic` в этой задаче не нужны.

Правила ошибок:

- `nil` вместо счёта — `ErrNilAccount`;
- отрицательный начальный баланс, а также нулевая или отрицательная сумма операции — `ErrInvalidAmount`;
- нехватка денег для снятия или перевода — `ErrInsufficientFunds`.

Ошибки можно оборачивать дополнительным контекстом, но `errors.Is` должен находить соответствующую sentinel error.

Перевод счёта на самого себя успешен, если сумма корректна и на счёте достаточно денег; баланс при этом не меняется.

Можно считать, что ни одна успешная операция в тестах не переполнит `int64`.
