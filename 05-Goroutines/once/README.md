# once

Инициализацию конфигурации могут одновременно запросить несколько горутин.
Нужен объект, который выполняет инициализацию один раз, а остальным позволяет
продолжить только после её окончания.

Реализуйте учебный аналог [sync.Once](https://pkg.go.dev/sync#Once) на каналах:

```go
func New() *Once
func (o *Once) Do(f func())
```

Экземпляр создаётся через `New()`. Поддержка нулевого значения `Once` не нужна.
После начала использования объект нельзя копировать.

Правила:

- Только один вызов `Do` выполняет свой `f`. У остальных вызовов `f` может
  быть другой — эти функции не вызываются.
- Каждый конкурентный вызов `Do` ждёт окончания единственного запущенного `f`.
  После возврата из `Do` результаты инициализации доступны вызывающей горутине.
- Если `f` паникует, паника выходит из этого вызова `Do`. Инициализация всё
  равно считается выполненной: другие вызовы освобождаются и больше не вызывают `f`.
- Если `f` вызывает `Do` на том же объекте, получится взаимная блокировка.
  Обрабатывать такой ошибочный сценарий не требуется.

Например, при трёх конкурентных запросах инициализации недостаточно просто
пометить объект «уже запускали»: два запроса не должны уйти, пока первый
ещё загружает конфигурацию.

Использование `sync` и `sync/atomic` в реализации запрещено. Нельзя проверять
готовность в цикле с `default`, `time.Sleep` или `runtime.Gosched`: ожидание
должно блокировать горутину. Дополнительная постоянно работающая горутина
для `Once` не нужна.

Проверка из корня репозитория:

```shell
go test ./05-Goroutines/once/...
go test -race ./05-Goroutines/once/...
```
