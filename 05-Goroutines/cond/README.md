# cond — бонус

Задача выходит за рамки основной лекции и даёт 100 бонусных баллов.

Condition variable позволяет ждать изменения общего состояния. Например,
получатель очереди ждёт, пока в ней появится элемент. Состояние защищено
внешней блокировкой, но во время ожидания её надо отпустить, чтобы
производитель смог изменить очередь.

Реализуйте учебный аналог [sync.Cond](https://pkg.go.dev/sync#Cond) на каналах:

```go
type Locker interface {
    Lock()
    Unlock()
}

type Cond struct {
    L Locker
}

func New(l Locker) *Cond
func (c *Cond) Wait()
func (c *Cond) Signal()
func (c *Cond) Broadcast()
```

`Locker` дан в шаблоне. Им может быть любой корректный mutex. Реализация
`Cond` не должна импортировать `sync` или `sync/atomic`; тесты могут передавать
ей готовую блокировку. Экземпляр создаётся через `New` и не копируется.

Правила:

- Вызывающая горутина уже держит `L`, когда входит в `Wait`.
- `Wait` регистрирует текущего ожидающего **до** отпускания `L`, отпускает `L`
  и блокируется. После уведомления он снова берёт `L` и только потом возвращается.
  Уведомление между регистрацией и засыпанием не должно потеряться.
- `Signal` уведомляет одного ожидающего: самого раннего из зарегистрированных
  и ещё не уведомлённых. При пустой очереди это no-op; сигнал не запасается на будущее.
- `Broadcast` уведомляет всех зарегистрированных ожидающих. При пустой очереди
  это no-op. Горутину, зарегистрированную после уведомления, он не будит.
- `Signal`/`Broadcast` могут вызываться как с взятой `L`, так и без неё.

FIFO относится к **выбору ожидающего** в `Signal`, а не к порядку, в котором
разбуженные горутины получат `L` или продолжат работать. После пробуждения
состояние мог изменить кто-то другой, поэтому вызывающий код проверяет условие
в цикле:

```go
c.L.Lock()
for len(queue) == 0 {
    c.Wait()
}
// Пока L взята, можно забрать элемент queue.
c.L.Unlock()
```

Это блокирующее ожидание, а не busy wait: каждый вызов `Wait` засыпает
до уведомления. Активное ожидание, `Sleep`/`Gosched` вместо уведомлений
и фоновые горутины, остающиеся жить после использования, запрещены.
Проверять, взята ли произвольная `Locker`, отдельно не требуется:
корректное использование гарантируется вызывающим кодом.

Проверка из корня репозитория:

```shell
go test ./05-Goroutines/cond/...
go test -race ./05-Goroutines/cond/...
```
