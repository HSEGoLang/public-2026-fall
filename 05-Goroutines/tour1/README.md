# tour1

Пройдите часть [Concurrency в A Tour of Go](https://go.dev/tour/concurrency/1):
горутины, каналы, `select` и упражнения.

Часть Methods and interfaces относится к предыдущей лекции; проходить
её повторно для этой задачи не нужно.

После прохождения всех страниц Concurrency измените функцию `Tour`, чтобы
она возвращала строку `"tour1 done!"`, и отправьте решение.

Проверка из корня репозитория:

```shell
go test ./05-Goroutines/tour1/...
```
