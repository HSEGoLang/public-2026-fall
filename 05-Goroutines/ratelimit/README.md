# ratelimit — бонус

Задача даёт 100 бонусных баллов и требует самостоятельной работы с временем
и отменой. Основная часть лекции знакомит с `ctx.Done()`; скользящее окно
и реализацию ограничителя нужно спроектировать самостоятельно.

Реализуйте примитив, ограничивающий частоту действий:

```go
func NewLimiter(maxCount int, interval time.Duration) *Limiter
func (l *Limiter) Acquire(ctx context.Context) error
func (l *Limiter) Stop()
```

Успешный `Acquire` выдаёт разрешение выполнить одно действие. На любом
полуоткрытом промежутке времени `[t, t+interval)` должно выдаваться не больше
`maxCount` разрешений. Это **скользящее окно**, а не отдельные календарные секунды.

Например, для `maxCount=2` и `interval=1s` первые два одновременных запроса
проходят сразу. Третий ждёт, пока первое разрешение окажется за пределами
окна. Ограничитель не отбирает разрешения обратно, и после действия не
требуется вызывать `Release`.

Контракт:

- `maxCount` положителен; `interval` неотрицателен. Неверные параметры
  приводят к панике в `NewLimiter`.
- При `interval == 0` ограничителя частоты нет, но отмена и `Stop` работают.
- `Acquire` можно вызывать конкурентно. Если контекст уже отменён до вызова,
  разрешение не выдаётся: возвращается `ctx.Err()`.
- Во время ожидания отмена узнаётся по закрытию `ctx.Done()` и приводит к
  ошибке `ctx.Err()`. Отменённый запрос не расходует разрешение. Если отмена
  и доступность разрешения происходят одновременно, допустим любой из исходов.
- `Stop` освобождает ожидающие вызовы и останавливает внутреннюю горутину.
  После его возврата новые вызовы получают `ErrStopped`. Если одновременно
  отменён контекст, допустимы `ErrStopped` или `ctx.Err()`.
- `Stop` безопасно вызывать несколько раз, в том числе конкурентно.
  Каждый вызов ждёт завершения внутренней горутины.

`ErrStopped` уже объявлена в шаблоне. `ctx` не бывает `nil`.

Нужно решение с **одной управляющей горутиной**, запускаемой в `NewLimiter`.
Она владеет историей выданных разрешений. Отдельная горутина на каждый
`Acquire` или разрешение не нужна. Использование `sync` и `sync/atomic`
в реализации запрещено; блокировка и уведомления делаются каналами.

Не опрашивайте время в цикле. Для ожидания ближайшего освобождения места
подойдёт [time.Timer](https://pkg.go.dev/time#Timer), который участвует в
`select` вместе с остановкой. Для отмены прочитайте контракт
[Context.Done и Context.Err](https://pkg.go.dev/context#Context).
Никаких горутин после `Stop` оставаться не должно.

Проверка из корня репозитория:

```shell
go test ./05-Goroutines/ratelimit/...
go test -race ./05-Goroutines/ratelimit/...
```
