# speller

Реализуйте `speller.Spell`. Функция принимает число из диапазона от `-999999999999` до `999999999999` и возвращает его американское написание.

Примеры:

```text
7    -> "seven"
42   -> "forty-two"
110  -> "one hundred ten"
-301 -> "minus three hundred one"
```

Правила:

- в американском варианте не используется `and`;
- числа от 21 до 99, не кратные 10, пишутся через дефис;
- части между `hundred`, `thousand`, `million` и `billion` разделяются одним пробелом;
- в результате не должно быть лишних пробелов.

Таблицы слов и разрядов уже даны в `words.go`: переписывать английские числительные не нужно. Удобно разложить число на трёхзначные группы и отдельно написать helper для числа меньше 1000. Заготовка `spellUnderThousand` для этого уже есть в `speller.go`.
