# spacecollapse

Реализуйте `spacecollapse.CollapseSpaces`.

Функция получает Unicode-строку и заменяет каждую непустую группу подряд идущих пробельных рун на один обычный ASCII-пробел.

```text
"  Hello,\t\nмир!  " -> " Hello, мир! "
```

Пробельность руны нужно определять функцией `unicode.IsSpace`. Группа в начале или конце входа тоже превращается в один пробел, а не удаляется.

Каждый байт, не образующий корректную UTF-8-последовательность, нужно заменить на `utf8.RuneError` (U+FFFD).

Ограничений на allocations или время работы в этом задании нет.
