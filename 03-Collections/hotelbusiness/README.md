# hotelbusiness

Отель получил список будущих заездов. Для каждого гостя известны день заезда `CheckInDate` и день выезда `CheckOutDate`.

Реализуйте `hotelbusiness.ComputeLoad`, которая преобразует список гостей в timeline загрузки отеля. Каждый `Load` задаёт день, с которого в отеле находится `GuestCount` гостей.

Можно считать, что вход корректен: для каждого гостя `CheckInDate < CheckOutDate`. Даты могут быть отрицательными и очень далёкими друг от друга: обходить каждый календарный день нельзя. В тестах может быть до 100 000 гостей, поэтому квадратичный алгоритм тоже не подойдёт.

Правила:

- в один день выезды происходят до заездов; в итоге нужно вернуть число гостей после всех событий этого дня;
- в результат попадают только даты, в которые итоговая загрузка изменяется;
- элементы результата идут по возрастанию `StartDate`;
- функция не изменяет входной slice;
- для пустого входа нужно вернуть пустой результат; допустимы и `nil`, и `[]Load{}`.

Пример:

```go
guests := []hotelbusiness.Guest{
	{CheckInDate: 1, CheckOutDate: 3},
	{CheckInDate: 2, CheckOutDate: 4},
	{CheckInDate: 3, CheckOutDate: 5},
}
```

Для такого входа результат равен:

```go
[]hotelbusiness.Load{
	{StartDate: 1, GuestCount: 1},
	{StartDate: 2, GuestCount: 2},
	{StartDate: 4, GuestCount: 1},
	{StartDate: 5, GuestCount: 0},
}
```

Обратите внимание: в день 3 один гость выехал, а другой заехал. Итоговая загрузка не изменилась, поэтому записи для дня 3 нет.
