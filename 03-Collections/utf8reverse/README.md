# utf8reverse

Реализуйте `utf8reverse.Reverse`.

Функция должна вернуть строку из тех же Unicode code points (рун), но в обратном порядке.

```text
"Hello, 世界" -> "界世 ,olleH"
```

Каждый байт входа, который не образует корректную UTF-8-последовательность, нужно заменить на `utf8.RuneError` (U+FFFD).

Мы разворачиваем именно руны, а не пользовательские графемы. Поэтому emoji, флаги и буквы с combining marks могут «распасться» — для этой задачи это ожидаемо.

Ограничений на количество allocations или время работы в этом задании нет.
