# postfix

Реализуйте `postfix.Eval` — вычислитель арифметических выражений в постфиксной записи.

В такой записи операция идёт после двух операндов:

```text
"2 3 +"       -> 5
"10 2 3 * -" -> 4
```

Токены разделяются любым непустым набором Unicode-пробелов. Числа имеют тип `int` и могут быть отрицательными. Нужно поддержать `+`, `-`, `*` и целочисленное `/`. Деление ведёт себя как оператор `/` для `int` в Go: результат округляется к нулю.

Удобно хранить промежуточные значения в slice, используя его как stack. Для операции сначала снимается правый, затем левый операнд. Это важно для вычитания и деления.

Правила ошибок:

- пустая строка, нехватка операндов или лишние числа в stack после обхода — `ErrInvalidExpression`;
- неизвестный токен — `ErrUnknownToken`;
- деление на ноль — `ErrDivisionByZero`.

Ошибки можно оборачивать контекстом, но они должны определяться через `errors.Is`.
