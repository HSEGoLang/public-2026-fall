# tabletest

Протестируйте предоставленную `ParseDuration`, добившись покрытия пакета
не менее 95% statements. Это самостоятельная учебная реализация, её контракт
задаётся кодом и комментариями в `parse_duration.go`, а не текущей версией
`time.ParseDuration`.

Свои тесты пишите в новом файле `*_test.go`. Не меняйте `coverage_test.go`
и `parse_duration.go`: grader восстанавливает защищённые файлы.

Используйте table driven tests. У каждого случая должны быть вход,
ожидаемая длительность и признак ожидаемой ошибки. Проверяйте результат,
а не только вызывайте функцию ради покрытия. Подумайте о пустом вводе,
знаке, дробной части, единицах, составной длительности и переполнении.

Из корня репозитория:

```shell
go test -coverprofile=/tmp/tabletest.cover ./06-Testing/tabletest/...
go tool cover -func=/tmp/tabletest.cover
go tool cover -html=/tmp/tabletest.cover
```

Grader считает покрытие всего пакета, включая вспомогательные функции.
Имеющиеся у преподавателя тесты не заменяют ваши тесты при оценивании.
Процент покрытия помогает найти непроверенные строки, но сам по себе
не доказывает корректность проверок.

Справка: [table driven tests](https://go.dev/wiki/TableDrivenTests).
