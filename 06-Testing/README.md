# Тестирование

Четыре основные задачи — по 100 баллов, всего 400. Дополнительная
задача `tparallel` даёт 200 бонусных баллов.

| Задача | Что практикуем | Баллы |
| --- | --- | --- |
| [testequal](testequal/README.md) | Assert/Require, Helper, интерфейс тестового объекта | 100 |
| [tabletest](tabletest/README.md) | Таблица случаев, границы ввода, покрытие statements | 100 |
| [fileleak](fileleak/README.md) | Cleanup, владение ресурсом, снимки Linux-дескрипторов | 100 |
| [iprange](iprange/README.md) | Fuzzing, минимальный crash и регрессионный тест | 100 |
| [tparallel](tparallel/README.md), бонус | Порядок родителей/детей и барьеры параллельных тестов | +200 |

Рекомендуемый порядок — сверху вниз. Основная часть опирается на лекцию 6
и упражнения семинара: проверка функции, таблицы случаев, тестовый объект,
Cleanup и воспроизведение некорректного входа.

`fileleak` выполняется на Linux: используйте Linux, WSL2, контейнер или CI.
Проверка компиляции на другой ОС не запускает его Linux-тесты. `tparallel`
соединяет правила параллельных тестов с материалом горутин и каналов;
для основной части решать его не требуется.

Команды запускаются из корня репозитория:

```shell
go test ./06-Testing/testequal/...
go test -coverprofile=/tmp/tabletest.cover ./06-Testing/tabletest/...
go test ./06-Testing/fileleak/...
go test ./06-Testing/iprange/...
```

До реализации шаблоны компилируются, но тесты задач с заглушками падают.
Точные контракты, ограничения и команды fuzzing указаны в условиях задач.
