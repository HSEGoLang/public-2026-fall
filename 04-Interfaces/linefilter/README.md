# linefilter

Сервис получает текстовый поток и оставляет только подходящие строки.
Реализуйте:

```go
func Filter(dst io.Writer, src io.Reader, keep func(string) bool) (int, error)
```

`keep` вызывается ровно один раз для каждой прочитанной строки, в порядке
входа. `true` означает, что строку нужно записать. В результате возвращаются
число **полностью записанных** строк и ошибка.

## Контракт строк

- Разделитель — только `\n`. Callback получает текст без него. `\r` — обычный
  символ; пробелы и Unicode не нормализуются.
- Каждая выбранная строка записывается с одним завершающим `\n`.
- Непустой остаток при EOF считается последней строкой, даже без `\n`.
- Пустые строки тоже обрабатываются: `"\n"` — одна пустая строка.
  Пустой вход — ноль строк; завершающий `\n` не создаёт дополнительной строки.
- Строки могут быть длиннее 64 KiB. Нельзя читать весь вход целиком: память
  O(длины максимальной строки), без накопления уже обработанных строк.

Например, для `"ok\n\nerror: disk"` и предиката `strings.HasPrefix(s, "error:")`
результат — `"error: disk\n"`, счётчик 1.

## Ошибки и владение

- EOF — нормальное завершение, в том числе вместе с последними данными.
- Другую ошибку чтения нужно обернуть контекстом и вернуть. Неполный остаток
  строки при такой ошибке не передаётся callback и не записывается.
  Завершённые предыдущие строки уже обработаны.
- Ошибка записи останавливает обработку и сохраняется для `errors.Is`.
  Если writer вернул меньше байт без ошибки, верните `io.ErrShortWrite`
  (можно обёрнутую). Эта строка в счётчик не входит.
- Потоки открывает и закрывает вызывающий код. `Filter` не вызывает Close.
- `src`, `dst`, `keep` ненулевые и соблюдают свои контракты; конкурентных
  вызовов нет. После сбоя не начинайте следующую итерацию обработки; уже
  прочитанные внутренним буфером bytes возвращать назад не требуется.

Подсказка: `bufio.Reader.ReadString` умеет читать длинные строки. Сначала
разберите различие EOF и прочих ошибок, затем добавляйте callback и запись.

```shell
go test ./04-Interfaces/linefilter/...
```
