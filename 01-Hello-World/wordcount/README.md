# wordcount

Напишите консольную утилиту, которая принимает имена файлов в аргументах командной строки и печатает повторяющиеся **строки целиком** и число их вхождений во всех файлах вместе. Несмотря на название задачи, отдельные слова считать не нужно.

В stdout попадают только строки, встретившиеся хотя бы два раза. Порядок вывода произвольный. Формат каждой записи: число, табуляция, исходная строка и перевод строки:

```text
<COUNT>\t<LINE>
```

Например, если и `a.txt`, и `b.txt` содержат:

```text
a
b
a
c
```

то запуск `wordcount a.txt b.txt` выдаст, с точностью до порядка:

```text
4	a
2	b
2	c
```

Пустая строка тоже считается строкой. Завершающий перевод строки сам по себе не добавляет ещё одну пустую строку: файл `a\n` содержит одну строку, а `a\n\n` — две. Пробелы внутри строки сохраняются, поэтому `a` и ` a` — разные строки. Без аргументов вывод пустой.

## Как получить решение из примера лекции

В первой лекции уже есть счётчик строк: пример [`uniq`](../../lectures/01-intro/uniq/uniq.go) на слайде **uniq**. Возьмите его за основу.

Разница небольшая: `uniq` читает `os.Stdin` и выводит все строки, а здесь нужно прочитать перечисленные файлы в один общий счётчик и вывести только повторы. Ниже даны все необходимые части — их можно собрать, ещё не изучив Go подробно.

### 1. Подготовьте main.go

Работайте в `01-Hello-World/wordcount/main.go`. Сохраните первую строку `//go:build !solution` и пустую строку после неё. `package main` означает исполняемую программу; функция `main` запускается первой.

Под `package main` добавьте импорты:

```go
import (
	"bufio"
	"fmt"
	"os"
)
```

### 2. Прочитайте один файл

Добавьте рядом с `main`, вне её тела, функцию:

```go
func countFile(filename string, counts map[string]int) error {
	file, err := os.Open(filename)
	if err != nil {
		return err
	}
	defer file.Close()

	input := bufio.NewScanner(file)
	for input.Scan() {
		counts[input.Text()]++
	}

	return input.Err()
}
```

- `os.Open` открывает файл и возвращает файл вместе с ошибкой. `err != nil` означает, что открыть его не удалось.
- `defer file.Close()` закроет файл при выходе из `countFile`, в том числе при ошибке чтения.
- `bufio.NewScanner(file)` — тот же scanner, что в лекции, только вместо стандартного ввода ему передаётся файл.
- `Scan()` переходит к следующей строке, `Text()` возвращает её без перевода строки. Scanner также обрабатывает окончания строк Windows (`\r\n`).
- `counts[line]++` увеличивает счётчик строки. Для нового ключа исходное значение равно нулю. Переданная map общая, поэтому изменения сохранятся в `main`.
- `input.Err()` позволяет отличить конец файла от ошибки чтения. Стандартного лимита Scanner около 64 КиБ на строку достаточно для примеров этой задачи; для более длинных строк лимит настраивается через `Scanner.Buffer`.

### 3. Обойдите аргументы и напечатайте повторы

В `main` создайте map **один раз, до обхода файлов**:

```go
counts := make(map[string]int)

for _, filename := range os.Args[1:] {
	if err := countFile(filename, counts); err != nil {
		fmt.Fprintf(os.Stderr, "wordcount: %v\n", err)
	}
}
```

`os.Args[0]` — имя программы; `os.Args[1:]` — все аргументы после него. `range` перебирает имена файлов, а `_` означает, что индекс элемента нам не нужен. Ошибка пишется в stderr, после чего программа пробует следующий файл.

После этого цикла, всё ещё внутри `main`, добавьте вывод из `uniq` с одним условием:

```go
for line, n := range counts {
	if n > 1 {
		fmt.Printf("%d\t%s\n", n, line)
	}
}
```

`%d` подставляет число, `%s` — строку, `\t` — табуляцию, `\n` — перевод строки. Нужен именно `Printf`, потому что `Println` не подставляет значения в шаблон. Не печатайте приглашения ко вводу, имена файлов и отладочные сообщения в stdout: тесты ждут только пары «количество — строка».

## Запуск, проверка и сдача

Все команды ниже выполняются **из корня личного репозитория**. На Windows используйте **Git Bash**. Создайте там `a.txt` и `b.txt` из примера, затем запустите:

```shell
go run ./01-Hello-World/wordcount a.txt b.txt
go test -v ./01-Hello-World/wordcount/...
make format 01-Hello-World/wordcount
golangci-lint run ./01-Hello-World/wordcount/...
```

Без `make` замените форматирование двумя командами:

```shell
golangci-lint run --no-config --enable-only wsl_v5 --fix ./01-Hello-World/wordcount/...
golangci-lint fmt ./01-Hello-World/wordcount/...
```

Чтобы собрать отдельный исполняемый файл, можно выполнить `go install ./01-Hello-World/wordcount`; он появится в `GOBIN`, а если этот параметр не задан — в `bin` внутри `go env GOPATH`. Для тестов достаточно `go run` и `go test`, установка программы не обязательна.

Отправьте только решение:

```shell
git add 01-Hello-World/wordcount/main.go
git commit -m "Solve wordcount"
git push origin main
```

Дождитесь результата в **My Submits**. Настройка инструментов, повторная проверка и получение новых ДЗ разобраны в инструкции к [`sum`](../sum/README.md).
