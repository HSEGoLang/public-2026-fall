# Примеры лекции 7

Команды запускаются из указанной папки примера, а не из `lectures/`.
Каждый этап — самостоятельный снимок проекта; изменения одного этапа
не влияют на другие. Нужен Go 1.27 или новее.

| Каталог | Команда | Результат |
| --- | --- | --- |
| `01-hello` | `go run .` | `Hello, world!` |
| `02-packages` | `go run .` | `Hello, Go!` |
| `03-cmp` | `go run .` | `ReverseRunes: mismatch (-want +got)`, затем разница строк |
| `04-local/hello` | `go run .` | `Hello, Go!` |
| `05-mvs/hello` | `go run .` | `morestrings: OK`, затем `moreints: OK` |
| `06-workspace/hello` | `go run .` | `morestrings: OK`, затем `moreints: OK` |
| `07-v2/hello` | `go run .` | `Hello, Go!` |

У `03-cmp`, `05-mvs` и `06-workspace` внешние зависимости зафиксированы;
при первом запуске нужна сеть либо заполненный кеш. Остальные примеры
используют стандартную библиотеку и предоставленные локальные модули.
В `03-cmp` ожидание специально отличается от результата правильной
`ReverseRunes`: так виден смысл диагностики.
`cmp.Diff` не гарантирует точный формат: пробелы могут различаться.
`06-workspace` запускается с его собственным `go.work`; для остальных
можно задать `GOWORK=off` только на время команды.
